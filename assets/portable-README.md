# What the Port · Windows

**모두 압축을 푼 뒤 `WhatThePort.exe`를 더블클릭하세요.**

Windows 10/11 x64 · .NET Framework 4.8 · 관리자 권한 불필요.

버전별 추가·개선·수정 사항: [변경 기록](docs/CHANGELOG.md). 앱 설정에서도 현재 버전을 확인할 수 있습니다.

| 파일·폴더 | 용도 |
|---|---|
| **WhatThePort.exe** | **실행할 앱 본체** |
| wtp.exe | 터미널용 명령 도구. 인수 없이 실행하면 본체를 열고 종료 |
| WhatThePort.Core.dll | 서버 조회·정책 라이브러리. 본체와 함께 유지 |
| WhatThePort.exe.config | .NET 실행·접근성 설정. 본체와 함께 유지 |
| fonts | 화면에 쓰는 글꼴과 글꼴 라이선스. 본체와 함께 유지 |
| docs | 상세 사용 가이드와 설명 이미지 |
| README.md / LICENSE | 이 안내문과 프로그램 라이선스 |

파일 수는 실행 중인 프로그램 수가 아닙니다. `wtp.exe`를 인수 없이 실행해도 상주하는 앱은 본체 하나이며, 이미 실행 중이면 기존 창을 엽니다.

앱 화면의 RAM·CPU 수치는 감시하는 서버의 사용량입니다. What the Port 자체의 사용량은 Windows 작업 관리자에서 `WhatThePort.exe`를 확인하세요. 기본 조회 주기는 3초이고, 트레이에 숨긴 동안 화면을 다시 그리지 않습니다. 설정에서 조회 주기를 늘릴 수 있습니다.

- 트레이 아이콘 / **Ctrl+Alt+P**: 패널 표시·숨김
- **× / Esc**: 트레이로 숨김. 감시는 계속됩니다.
- 트레이 우클릭 → **앱 종료 / Quit**: 프로그램 종료
- 새 버전으로 교체할 때는 기존 앱을 종료한 뒤 새 `WhatThePort.exe` 실행
- 서버 자동 정리는 기본 **Off**

Ctrl+Alt+P는 창이 열려 있으면 숨기고, 다시 누르면 보여 줍니다. 숨겨도 감시는 계속됩니다. 하단의 **3초마다 갱신**은 서버 조회 간격입니다.

서버 상세의 **프로젝트 연결**에서는 에이전트 세션 ID와 Vercel 주소를 직접 등록합니다. 둘 다 선택 사항이며, 사용하지 않으면 비워 두세요. **A**는 등록 세션 재개, **↗**는 등록된 Vercel 주소 열기, **>_**는 프로젝트 폴더에서 터미널 열기입니다. 미등록 상태에서 A·↗를 누르면 등록 안내가 나옵니다. 입력란별 설명과 저장·취소 동작은 [프로젝트와 세션 연결](docs/usage.md#프로젝트와-세션-연결)에 있습니다.

터미널에서 목록을 확인하려면 압축을 푼 폴더에서 실행하세요.

```powershell
.\wtp.exe list
.\wtp.exe list --json
.\wtp.exe --help
```

위 조회 명령은 PowerShell·명령 프롬프트(CMD) 모두에서 사용할 수 있습니다. 서버 목록을 보는 데 `wtp link` 등록은 필요하지 않습니다.

`link`는 세션·미리보기 연결을 저장하는 선택 기능입니다. `--folder`에는 이 앱을 압축 해제한 폴더가 아닌 **실제 개발 프로젝트 폴더**를 입력합니다. 서버 상세의 **폴더**에서 경로를 확인하세요. `C:\dev\my-app`, 포트 `3000`, `YOUR_SESSION_ID`는 예시이며 본인의 값으로 바꿔야 합니다. 세션 ID를 모르면 생략하세요. **Choose an existing absolute project folder.** 오류는 입력한 폴더가 없다는 뜻입니다. 앱의 **서버 상세 → 프로젝트 연결**에서도 등록할 수 있습니다.
