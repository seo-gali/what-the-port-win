## 언어 선택

기본 한국어. **설정 → 언어 / Language → 한국어 또는 English**를 선택하면 화면 언어를 즉시 미리 볼 수 있다. 입력 중인 다른 설정값도 유지된다. **설정 저장 / Save preferences**를 누르면 다음 실행에도 유지되며, **취소 / Cancel**, 뒤로 가기 또는 Esc를 누르면 저장 전 언어와 설정으로 돌아간다. 트레이로 숨겼다가 다시 열면 미리보기와 입력값이 유지된다.

## 실행했는데 창이 보이지 않을 때

창의 **가장자리·모서리를 드래그**해 크기를 조절한다. 선택한 크기는 저장되며 목록·설정·상세·프로젝트 연결을 오가도 위치와 크기가 유지된다. 긴 본문만 스크롤하고 하단 버튼은 계속 표시한다. 설정의 수치 입력 네 개는 한 줄에 두 개씩 배치한다.

최소 크기는 **344×460 DIP**다. 글꼴 크기는 창 크기와 별도로 설정에서 **80–125%**를 5% 단위로 조절한다. 선택 즉시 미리 보며 저장하면 유지하고 취소·뒤로·Esc는 이전 비율로 복원한다. 글자와 함께 행·간격·차트도 비례 조절하고, 목록 그래프의 너비는 남는 공간을 따른다. 조회 표본이나 시간 범위를 임의로 늘리지는 않는다. 창·화면·그래프에 별도 전환 애니메이션은 적용하지 않는다.

**설정 → Windows 로그인 시 자동 실행**을 켜고 저장하면 현재 EXE를 사용자 시작프로그램에 등록한다. 로그인 시에는 트레이에서 시작한다. 끄고 저장하면 해제하며 취소는 등록을 바꾸지 않는다. 포터블 EXE를 옮겼다면 새 위치에서 켜고 다시 저장한다. **배경 불투명도**는 40–100%로 미리 보고 저장할 수 있으며 취소하면 복원한다. **알림 1시간 쉬기**는 설정과 트레이에서 같은 상태를 표시하고, 쉬는 동안 다시 누르면 즉시 재개한다.

- **WhatThePort.exe:** 트레이 앱 본체. 더블클릭으로 실행하는 파일.
- **wtp.exe:** PowerShell·터미널용 명령 도구. `wtp list`·`wtp link` 지원. 인수 없이 실행 시 같은 폴더의 `WhatThePort.exe` 호출.

- **기존 앱 실행 중:** 다른 폴더의 EXE도 실행 중인 앱의 창 열기로 연결. 새 버전으로 교체할 때는 기존 트레이 → 앱 종료 / Quit 후 새 EXE 실행.
- **저장된 위치:** 재실행 시 저장한 모니터·위치에서 표시. `Ctrl+Alt+P` 또는 트레이 아이콘으로 표시·숨김. 설정 → 창 위치 초기화로 주 모니터 복귀.
- **실행 직후 표시:** EXE 직접 실행·재실행 시 첫 마우스·키보드 조작 전까지 자동 숨김 보류. 이후 기존 자동 숨김 적용. ×·Esc로 즉시 숨김 가능.
- **단일 EXE:** 홈페이지의 기본 다운로드는 Core·폰트를 내장한 `WhatThePort.exe` 한 개. 압축 해제·설치 불필요. Windows의 .NET Framework 4.8 필요. `--licenses`로 MIT·폰트 라이선스 열람.
- **선택 ZIP:** `wtp.exe` CLI가 필요할 때 다운로드. 모두 압축 풀기 후 EXE·Core DLL·설정 파일·fonts 폴더를 함께 유지.
- **여러 파일이 있는 이유:** DLL·설정·fonts는 앱의 구성 요소이고, README·docs·LICENSE는 안내·라이선스. 각 파일이 별도 앱으로 상주하는 것은 아님. ZIP의 README에 파일별 용도 안내.
- **SmartScreen:** 다운로드 파일의 평판 확인에 따른 실행 전 경고. 앱 창 표시 문제와 별개이며 멀웨어 확정 판정이나 안전 보증을 의미하지 않음. 보호 기능 해제 없이 출처·검사 결과 확인 필요. [Microsoft 안내](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation).

## 그래프 읽기

목록·상세 그래프는 최근 측정 범위에 맞춰 세로축을 자동 조절한다. 상세의 위·아래 축 값으로 실제 메모리·CPU 범위를 확인한다. 기본 메모리 경고 2GB나 CPU 100%를 항상 축 끝으로 쓰지 않으므로 작은 변화도 보인다. 경고 판정 기준은 그대로이며, 기준선은 표시 범위에 있을 때 그린다. 값이 일정하면 선이 수평인 것이 정상이다.

## 선택할 수 없는 항목과 일부 종료

- **보호됨 · 종료 불가:** 이 앱·상위 실행 프로세스 또는 터미널·에이전트·시스템·DB·컨테이너 보호. 비활성 체크박스와 ◇ 표시는 정상 동작. 서버 행을 누르면 상세 화면의 안내 상자에서 전체 사유를 확인할 수 있다.
- **보호 앱:** wmux, cagent, Docker 등. 해당 앱의 종료 기능 사용.
- **일부 종료:** 서버 본체 종료 성공 후 하위 프로세스 종료 실패 가능. 포트가 닫히면 목록에서 제거. **종료 결과 상세**에서 프로세스별 오류·보호 제외 내역 확인.
- **본체 종료 실패:** 하위 프로세스 종료도 중단. 성공·실패를 되돌릴 수 있는 원자적 작업이 아님.

## 프로젝트와 세션 연결

서버 상세 → **세션·미리보기 연결 · URL 복사 (Link session & preview)** → 필요한 항목 입력 → **연결 저장 (Save links)**. 세션 ID와 Vercel 주소는 각각 선택 사항이다.

| 항목 | 기준 |
|---|---|
| 프로젝트 폴더 | 감지된 서버 폴더와 일치하는 기존의 절대 경로 |
| 에이전트 | Codex / Claude Code |
| 세션 ID | 로컬 CLI에서 재개 가능한 실제 세션 ID. 사용하지 않으면 빈칸 |
| 미리보기 | `https://….vercel.app` 형식의 등록 주소. 사용하지 않으면 빈칸 |
| 연결 키 | 프로젝트 폴더 + 포트; 다른 프로젝트의 포트 재사용 시 이전 링크 승계 방지 |

**실행 출처**는 부모 프로세스 기준 연관 정보다. **세션**에는 명시적으로 등록한 세션만 표시한다. **연결 앱**은 현재 TCP 연결 양쪽 끝점으로 확인한 같은 사용자의 로컬 프로세스이며, 다른 감지 서버에 속하면 프로젝트 이름도 표시한다. 연결 유지가 실제 요청 실행을 뜻하지 않으며 조회 사이에 끝난 짧은 호출과 외부 기기의 앱은 식별하지 못할 수 있다. 프로세스 더보기는 상단 프로젝트 정보 아래에 있다.

상세의 **>_**는 프로젝트 폴더에서 터미널 열기, **A**는 등록된 세션 재개, **↗**는 등록된 Vercel 주소 열기다. 미등록 항목의 실행 버튼은 숨기고 연결 관리 버튼 하나로 등록한다. 연결 화면의 뒤로 가기·취소·Esc는 이동해 온 서버 상세로 돌아간다. wmux 등 일반 앱의 내부 포트에는 세션·Vercel 연결이 필요하지 않을 수 있다.

**로컬 URL 복사**는 주소만 클립보드에 복사하며 입력 중인 연결 설정을 저장하지 않는다. **연결 저장**은 해당 폴더·포트의 입력값을 저장하고, **취소**는 저장 없이 상세로 돌아간다.

재개 전제: 선택한 에이전트 CLI 설치·로그인, 해당 CLI에서 접근 가능한 세션. 데스크톱 전용 세션의 CLI 재개 가능 여부는 사용 도구의 지원 범위에 따라 별도 확인 필요.

### CLI 링크 등록

서버 조회에는 링크 등록이 필요하지 않다. CLI는 홈페이지의 선택 ZIP에 포함된다. 압축을 푼 앱 폴더에서 아래 명령을 하나씩 실행한다. PowerShell과 명령 프롬프트(CMD) 모두 지원한다. 소스에서 빌드했다면 `dist` 폴더에서 실행한다.

```powershell
.\wtp.exe list
.\wtp.exe list --json
.\wtp.exe list --all
```

`wtp link`는 세션·미리보기 정보를 저장하는 선택 기능이다. 서버를 실행하거나 목록에 추가하지 않는다. 앱의 **서버 상세 → 프로젝트 연결**에서도 같은 내용을 등록할 수 있다.

- `--folder`: 개발 서버를 실행한 실제 프로젝트 폴더의 전체 경로. 앱의 서버 상세 **폴더**에서 확인한다. ZIP을 압축 해제한 `WhatThePort-Windows-x64` 폴더와 다르다. 직접 명령에 적는 경로는 공백을 고려해 큰따옴표로 감싼다.
- `--port`: 서버 목록의 실제 포트. 3000은 예시다.
- `--session`: 실제 세션 ID. `YOUR_SESSION_ID`는 안내용 표시이며 그대로 입력하지 않는다. 사용하지 않으면 생략한다.
- `--preview`: 실제 Vercel HTTPS 주소. 사용하지 않으면 생략한다.

아래는 **PowerShell 전용**으로 실제 값을 물어보는 등록 명령이다. `C:\…>` 형태의 CMD를 사용 중이면 먼저 `powershell -NoProfile`을 실행한다. 앱 폴더에서 실행하되, 입력할 프로젝트 경로는 서버 상세에서 확인한다.

**같은 폴더·포트의 기존 연결을 교체한다. 유지할 세션과 미리보기가 있다면 둘 다 입력한다. 빈칸인 항목은 저장된 연결에서도 비워진다.**

```powershell
& {
    $projectFolder = Join-Path (Read-Host '서버 상세에 표시된 프로젝트 폴더 전체 경로 (따옴표 없이)') '.' -ErrorAction Stop
    $serverPort = Read-Host '서버 목록에서 확인한 포트 번호'
    $sessionId = Read-Host '실제 세션 ID (사용하지 않으면 Enter)'
    $previewUrl = Read-Host '실제 Vercel HTTPS 주소 (사용하지 않으면 Enter)'
    $linkArgs = @('link', '--port', $serverPort, '--folder', $projectFolder)
    if ($sessionId) {
        $agent = Read-Host '에이전트: codex 또는 claude'
        $linkArgs += @('--agent', $agent, '--session', $sessionId)
    }
    if ($previewUrl) { $linkArgs += @('--preview', $previewUrl) }
    .\wtp.exe @linkArgs
}
```

`Choose an existing absolute project folder.`는 입력한 프로젝트 폴더가 없다는 뜻이다. 이전 예시 경로 `C:\dev\my-app`을 그대로 쓰지 말고 실제 프로젝트 경로를 입력한다. 오류를 없애려고 예시 폴더를 새로 만들 필요는 없다. 이 오류로 실패한 명령은 연결을 저장하지 않는다.

Vercel API 인증·배포 없음. 등록된 HTTPS 주소의 브라우저 열기만 지원. PowerShell·Windows Terminal 외의 사용자 지정 터미널 명령 미지원.

## 패널 위치

제목을 드래그하면 위치 자동 저장. 숨김·트레이 재열기·앱 재실행 후 복원. Ctrl+Shift+방향키로 키보드 이동. 저장 위치가 없으면 첫 실행은 주 모니터, 트레이 클릭은 해당 모니터 기준. 모니터 연결 해제 시 보이는 작업 영역으로 보정.

초기화: 설정 → **창 위치 초기화**. 핀(◇/◆)은 포커스를 잃었을 때 창 유지 여부이며, 위치 저장과 별개.

| Ctrl+, | 설정 |
| Ctrl+Shift+방향키 | 패널 이동·위치 저장 |
| 차트의 ← / → / Home / End | 이전·다음·첫·마지막 표본 |
| Tab / ↑ / ↓ / Enter | 컨트롤·서버 선택 / 상세 열기 |
| C | 목록에서 정리 화면 |
| O | 상세에서 로컬 URL 열기 |
| T | 상세에서 프로젝트 터미널 열기 |

Ctrl+Alt+P는 열려 있는 창을 숨기고 숨겨진 창을 다시 여는 단축키다. 숨겨도 서버 감시와 알림은 계속된다. 하단에는 이 단축키의 기능과 조회 간격(예: **3초마다 갱신**)을 표시한다. 앱 종료는 트레이 우클릭 → **앱 종료 / Quit**.

전역 단축키 충돌 시 트레이 아이콘으로 패널 열기. 창의 ×는 숨김, 트레이 우클릭 → **앱 종료 / Quit**은 앱 종료.

## 설정

### 앱 자체의 CPU·메모리

화면의 RAM·CPU는 감시 대상 서버의 사용량. 앱 자체의 사용량은 Windows 작업 관리자에서 `WhatThePort.exe` 확인. 기본 3초마다 조회하며 숨김 상태에서는 화면을 다시 그리지 않음. 서버별 이력은 최근 10분·최대 601개 표본으로 제한.

트레이로 시작하면 처음 열 때까지 패널 생성을 미룸. 창을 숨기면 목록·차트 컨트롤을 비우고 30초 뒤 창을 해제하며, 다시 열 때 최신 데이터·선택·핀 상태를 복원. 저장하지 않은 설정·프로젝트 링크 입력은 유지. WPF와 글꼴 캐시는 남을 수 있어 처음 시작할 때의 RAM 사용량으로 완전히 돌아가지는 않음. [실측 결과](resource-usage.md).

샘플 주기를 늘리면 조회 횟수와 상태·경고 반영 빈도가 함께 감소. ×·Esc는 창만 숨기므로 감시는 계속됨. 감시를 끝내려면 트레이 우클릭 → **앱 종료 / Quit**.

소스에서 재측정: `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/measure-resources.ps1`. Windows 작업 표시줄이 있는 데스크톱에서 실행. 격리된 설정·자동 정리 Off·기본 3초 주기로 실제 조회를 수행하며, 숨김·표시·다시 숨김을 각각 30초 측정. `-FixtureServers 5`를 추가하면 측정용 루프백 서버 다섯 개를 띄워 감시하며 해당 프로세스만 정리. 결과는 `artifacts/resource-usage.json`; CPU는 전체 논리 코어 대비 비율, RAM은 working set. 서버 수·환경에 따라 달라지며 장시간 누수 검증은 아님.

| CPU 경고 | 전체 논리 코어 대비 80%, 연속 3회 |
| 자동 정리 | Off / Ask / Automatic; 기본 Off |
| idle 기준 | 4시간; 연결 없음·CPU 2% 미만의 연속 관측 |
| 터미널 | PowerShell / Windows Terminal |
| 전체 리스너 | 사용자 정의 실행 파일·일반 앱의 TCP 리스너 포함 |

보호·경고 서버의 자동 정리 제외. 조회 실패·오래된 스냅샷의 자동 정리 중단. 실시간 요청 로그를 읽지 않는 표본 기반 idle 판정.

설정 저장 위치: `%LOCALAPPDATA%\WhatThePort\settings.json`.
프로젝트 링크 위치: 같은 폴더의 `links.json`.
손상된 설정: 자동 정리가 꺼진 기본값 복구 및 화면 안내. 수동 JSON 수정 후 앱 재실행 필요.

## 측정·종료 관련 참고

- **CPU** — 전체 논리 코어 대비 비율; 프로세스별 코어 사용률과 차이 가능
- **메모리** — resident working set; 공유 페이지 중복 및 실제 회수량 차이 가능
- **프로젝트 폴더** — 접근 가능한 x64/WOW64 프로세스의 현재 폴더 조회; 실패 시 프로세스 이름 표시
- **에이전트 식별** — 이름 변경·중간 셸에 따른 연관 식별 실패 가능
- **프로세스 종료** — 선택 트리의 즉시 종료; 저장·정리 훅 보장 없음
- **자동 재시작 서버** — 상위 npm 감시 프로세스가 재시작한 경우 원래 터미널에서 중지 필요
- **알림** — Windows 알림 설정·집중 지원에 따른 배너 미표시 가능
