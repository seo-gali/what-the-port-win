# 기능 확인 체크리스트

[README로 돌아가기](../README.md) · [사용 가이드](usage.md)

## 먼저 확인할 항목

| 확인 | 조작 | 기대 결과 |
|---|---|---|
| ☐ 패널 위치 | 목록 → 상세 → 링크 → 뒤로 → 정리 → 설정 반복 | 선택한 크기·위치 유지, 링크에서 해당 상세로 복귀, 작업표시줄 침범 없음 |
| ☐ 크기·글꼴·배경 | 모서리 드래그, 글꼴 비율·배경 불투명도 조절 → 취소/저장 | 크기와 글꼴 비율 독립, 본문만 스크롤, 취소 시 비율·불투명도 복원 |
| ☐ 시작·알림 | 로그인 자동 실행 켜기/끄기 저장, 알림 쉬기 두 번 | 바로가기 등록/해제, 알림 쉬기 후 재개 |
| ☐ 작은 작업 영역 | 현재 배율에서 상세·설정 열기, 본문 끝까지 스크롤 | 하단 실행·저장 버튼과 상태 표시 유지 |
| ☐ 모니터 이동 | 다른 모니터로 패널 드래그 후 상세·설정 전환 | 해당 모니터의 작업 영역 안에 표시 |
| ☐ 위치 저장 | 제목 드래그 → 숨김·트레이 재열기 → Quit·재실행 | 같은 위치 복원; 저장 위치가 트레이 모니터보다 우선 |
| ☐ 위치 초기화 | Settings → Reset panel position | 주 모니터 우측 하단으로 복귀 |
| ☐ 서버 탐지 | 직접 관리하는 개발 프로젝트의 서버 실행 | 기본 스캔 주기 약 3초 이후 해당 포트 표시 |
| ☐ 프로젝트 정보 | 해당 서버 상세 열기 | 예상 폴더·브랜치·포트·프로세스 확인 |
| ☐ 사용량 | 30초 이상 대기 후 직접 요청 발생 | 메모리·CPU 차트 표본 누적 |
| ☐ 로컬 URL | 자체 웹 개발 서버에서 O | 해당 서버의 브라우저 화면 |
| ☐ 터미널 | 폴더가 있는 자체 서버에서 T | 설정한 터미널 및 프로젝트 폴더 |
| ☐ 세션 재개 | 실제 세션 ID 저장 후 A | 등록한 에이전트의 해당 세션 |
| ☐ 미리보기 | 실제 Vercel 주소 저장 후 V | 등록 주소의 브라우저 화면 |

**전체 리스너 표시 시 유의점:** wmux, 디버거, 에이전트 등의 내부 포트 포함 가능. 모든 포트의 브라우저 응답 보장 없음. 현재 작업 중인 wmux·터미널·에이전트는 종료 시험 대상에서 제외.

**실행 출처·연결 앱·세션의 차이:** 실행 출처는 부모 프로세스 기준, 연결 앱은 현재 TCP 상대, 세션은 직접 등록한 ID다. 현재 연결이 실제 요청 실행을 의미하지는 않는다.

## 종료·정리 확인

1. `dist\WhatThePort.exe --demo` 실행 후 **Clean up** 선택·해제·종료 흐름 확인
2. 실제 모드에서는 종료해도 되는 자체 테스트 서버 하나만 선택
3. 종료 후 해당 포트의 목록 제거 및 다른 서버 유지 확인
4. 보호 표시된 프로세스의 종료 버튼·정리 선택 비활성 확인

데모의 실제 프로세스 종료 없음. 실제 종료는 즉시 종료 방식이며, 미저장 작업이 없는 테스트 서버만 사용.

## 설정·Windows 동작 확인

- [ ] 샘플 주기 변경 → Save preferences → Quit → 재실행 후 값 유지
- [ ] Ctrl+Alt+P 표시·숨김, Esc 복귀, Tab·방향키·Enter 탐색
- [ ] ◇ 핀 설정 후 다른 창 클릭 시 패널 유지, 해제 후 자동 숨김
- [ ] ×로 숨긴 뒤 트레이에서 복귀, Quit으로 실제 종료
- [ ] 자체 테스트 서버 기준 임계값 조정 후 트레이 경고색·Windows 알림 확인, 확인 후 임계값 복원
- [ ] 자동 정리가 기본 Off인지 확인; Ask 동작 확인 후 필요한 경우에만 Automatic 사용

## 추가 환경 검증

- [ ] 설정 → 언어 / Language에서 한국어·English 전환 후 재실행 시 유지 확인
- [ ] 보호된 항목의 선택 불가 안내 및 상태 도움말의 보호 이유 확인
- [ ] 자체 테스트 서버 종료 시 성공·일부 종료·본체 실패 안내 및 종료 결과 상세 확인
- [ ] 소개 페이지 `/what-the-port-win/`에서 ZIP 다운로드, 없는 중첩 주소의 홈 복귀 확인

| 항목 | 현재 확인 범위 | 남은 확인 |
|---|---|---|
| 위치·높이 | 실제 WPF 화면 전환, 100/125/150/200% 좌표 계산 테스트 | 물리 다중 모니터·혼합 DPI에서 직접 전환 |
| 종료 | 테스트가 만든 IPv4/IPv6 서버의 실제 종료·다른 서버 유지 | 사용 중인 개발 런타임별 종료 동작 |
| 세션·미리보기 | 명령 구성·입력 유효성·데모 실행 격리 | 실제 로그인·등록 링크로 이동 |
| Windows 알림 | 경고 정책·실앱 트레이 생성 | 실제 배너 수신·집중 지원 영향 |
| 자동 정리 | idle·보호·경고·조회 실패 정책 | 장시간 실사용·절전 복귀 |
| 설치 | 설치 스크립트 제공 | 사용자 폴더 설치·로그인 시작 등록 |

서명·온라인 배포·자동 업데이트·ARM64는 현재 검증 범위 밖.
